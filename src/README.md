SOLARDROP
Backend - Spring Boot

Como executar:

1. Iniciar a classe SolardropApplication
2. Esperar o Spring Boot iniciar
3. Abrir o navegador

Endpoints:

GET /solardrop
http://localhost:8080/solardrop

GET /sensor
http://localhost:8080/sensor?umidade=25

Exemplo:
Umidade: 25%
Precisa irrigar? true
